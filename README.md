Task Tracker

Project Description
- A web application that helps users organize projects and daily tasks. They can create projects, add tasks, as well as edit, delete, or complete their tasks. 

Tech used
-React
-JavaScript
-CSS
-Supabase
-PostgreSQL
-Vite

Database
The database contains two tables: Projects and Tasks

Projects
-ID
-User ID
-Name
-Description
-Created At

Tasks
-ID
-Project ID
-Title
-Description
-Status
-Priority
-Due Date
-Created At

Features
-User sign up and login
-Create and manage projects
-Add tasks
-Edit tasks
-Delete tasks
-Complete tasks
-Search tasks
-Task priority and due dates
